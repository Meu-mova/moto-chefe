# RADAR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Adicionar menu RADAR que permite buscar qualquer moto por chassi (parcial), incluindo vendidas.

**Architecture:** Server Component com form GET em `/radar`. Reutiliza `listarMotos` sem `excluirVendidas` para incluir motos vendidas. Tabela compacta seguindo padrão visual do Showroom.

**Tech Stack:** Next.js App Router (Server Components), Drizzle ORM, lucide-react, shadcn/ui (Badge, Table)

## Global Constraints

- Sem JavaScript client-side extra — form GET nativo
- Busca parcial via ILIKE já implementada em `listarMotos({ chassiBusca })`
- Não passar `excluirVendidas: true` para incluir motos vendidas
- Seguir padrão visual do Showroom (tabela compacta)
- Ícone `Radar` do lucide-react no sidebar
- Visível para todos os papéis (sem restrição)

- [ ] **Step 2: Criar `src/app/(dashboard)/radar/page.tsx`**

```tsx
import { listarMotos } from '@/lib/queries/motos'
import { Badge } from '@/components/ui/badge'
import { Table, TableBody, TableCell, TableHead, TableHeader, TableRow } from '@/components/ui/table'
import { buttonVariants } from '@/components/ui/button'
import { Eye, Search } from 'lucide-react'
import Link from 'next/link'
import { statusLabel, disponibilidadeLabel } from '@/lib/estado-moto'

export default async function RadarPage({
  searchParams,
}: {
  searchParams: Promise<{ q?: string }>
}) {
  const { q } = await searchParams
  const busca = q?.trim() ?? ''

  const motos = busca
    ? await listarMotos({ chassiBusca: busca })
    : []

  return (
    <div className="space-y-6">
      <div>
        <h1 className="text-2xl font-bold">RADAR</h1>
        <p className="text-slate-500 text-sm">Localize qualquer moto pelo chassi</p>
      </div>

      <form method="GET" className="flex gap-2 max-w-md">
        <div className="relative flex-1">
          <Search size={16} className="absolute left-3 top-1/2 -translate-y-1/2 text-slate-400" />
          <input
            name="q"
            defaultValue={busca}
            placeholder="Digite o chassi ou parte dele..."
            autoFocus
            className="w-full pl-9 pr-3 py-2 text-sm border border-slate-200 rounded-md focus:outline-none focus:ring-2 focus:ring-slate-400"
          />
        </div>
        <button
          type="submit"
          className={buttonVariants({ variant: 'default', size: 'default' })}
        >
          Buscar
        </button>
      </form>

      {!busca && (
        <p className="text-slate-400 text-sm">Digite um chassi acima para começar a busca.</p>
      )}

      {busca && motos.length === 0 && (
        <p className="text-slate-500 text-sm">Nenhuma moto encontrada para o chassi <strong>{busca}</strong>.</p>
      )}

      {motos.length > 0 && (
        <div className="bg-white rounded-lg border">
          <Table>
            <TableHeader>
              <TableRow>
                <TableHead>Chassi</TableHead>
                <TableHead>Modelo</TableHead>
                <TableHead>Cor</TableHead>
                <TableHead>Loja</TableHead>
                <TableHead>Status</TableHead>
                <TableHead>Disponibilidade</TableHead>
                <TableHead />
              </TableRow>
            </TableHeader>
            <TableBody>
              {motos.map((moto) => (
                <TableRow key={moto.id}>
                  <TableCell className="font-mono text-xs">{moto.chassi}</TableCell>
                  <TableCell className="font-medium">{moto.marca} {moto.modelo}</TableCell>
                  <TableCell>{moto.cor}</TableCell>
                  <TableCell>{moto.lojaNome}</TableCell>
                  <TableCell>
                    <Badge variant="outline">
                      {statusLabel[moto.status as keyof typeof statusLabel] ?? moto.status}
                    </Badge>
                  </TableCell>
                  <TableCell>
                    {moto.disponibilidade && (
                      <Badge variant="secondary">
                        {disponibilidadeLabel[moto.disponibilidade as keyof typeof disponibilidadeLabel] ?? moto.disponibilidade}
                      </Badge>
                    )}
                  </TableCell>
                  <TableCell>
                    <Link
                      href={`/estoque/${moto.id}`}
                      className={buttonVariants({ variant: 'ghost', size: 'sm' })}
                    >
                      <Eye size={14} className="mr-1" /> Ver
                    </Link>
                  </TableCell>
                </TableRow>
              ))}
            </TableBody>
          </Table>
        </div>
      )}
    </div>
  )
}
```
